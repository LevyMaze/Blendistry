# TypeScript Guide for Beginners

TypeScript brings **type safety** to JavaScript without losing flexibility.  

## Why TypeScript?
- Prevent runtime errors
- Better developer tooling
- Easier refactoring

function greet(name: string): string {
  return `Hello, ${name}`;
